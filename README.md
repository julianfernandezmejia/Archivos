# Personal academic webpage (GitHub Pages)

This repository includes a GitHub Pages-ready personal webpage inspired by:
- `academicpages.github.io` structure (multi-page academic profile site)
- content and tab layout from `https://sites.google.com/view/julianfernandezmejia/`

## Pages
- Home (`index.html`)
- Vitae (`vitae.html`)
- Research (`research.html`)
- Teaching (`teaching.html`)
  - Financial Theory 2025
  - International Finance 2025
  - Office Hours
- Useful Links (`useful-links.html`)

## Publish in GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Set source to **Deploy from a branch**, branch `main`/`work`, folder `/ (root)`.
4. Save and wait for deployment.
